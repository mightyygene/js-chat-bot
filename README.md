# Chat-bot

Простой веб-чат-бот на JavaScript с поддержкой команд, адаптивным интерфейсом и анимацией набора текста.

## Функционал

- Команды:
  - `/start` - начать общение
  - `/name: имя` - задать имя
  - `/number: 1 + 2` - вычисление выражений
  - `/number: 1, 2` -> выбор операции (+ - * /)
  - `/stop` - завершить диалог

- Поддержка операций:
  - сложение
  - вычитание
  - умножение
  - деление (с проверкой деления на 0)

- UI:
  - чат как в мессенджере (пузырьки)
  - аватарки пользователя и бота
  - авто-скролл вниз
  - отправка по Enter
  - кнопка отправки (SVG)
  - анимация «печатает…» (3 точки)

---

## Адаптивность

- На телефоне - интерфейс во весь экран
- На ПК - центрированный чат с ограничением ширины
- Используется:
  - `viewport`
  - `clamp()`
  - `100dvh`
